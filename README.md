# Vigie — démonstration publique

Version statique de présentation de Vigie, conçue pour GitHub Pages. Tous les exemples initiaux sont fictifs. Aucune base, pièce jointe réelle, clé, session ou configuration d'entreprise n'est incluse.

## Parcours disponibles

Consultation, recherche et filtres, fiches et échanges fictifs, création et modification de demandes, commentaires, changement de statut, export CSV, pilotage, simulation de quatre rôles et essai du concepteur. Les modifications restent dans le stockage de session du navigateur. Le bouton Réinitialiser rétablit les exemples.

Les comptes, équipes et rôles administratifs sont consultables uniquement. Le journal est une simulation locale aux essais de chaque visiteur. Aucune authentification réelle ni intégration Outlook, SAP ou SSO. Ne saisir aucune donnée réelle.

## Publication

Publier uniquement les fichiers de ce dossier dans un dépôt dédié. Dans Settings → Pages, choisir « Deploy from a branch », branche main, dossier /(root), puis Save. Le fichier .nojekyll conserve le fonctionnement statique.

GitHub Pages ne garantit pas l'accès depuis un réseau d'entreprise. En cas de blocage, demander à l'IT de valider l'URL ou d'héberger la démonstration sur un espace autorisé.
